Stacklight design mockups

Static HTML/CSS for the React build to follow. Append ?theme=dark or ?theme=light to any link; add &tab=trace|queue on a narrow window. Figures are illustrative.

Chat (full screen: chat, trace, queue)

  • Idle / first load state=idle
  • Mid-stream state=streaming
  • Answer with citations state=answer
  • Answer + source drawer state=answer&drawer=1
  • Abstention: “I’m not sure” state=abstain
  • Demo paused (budget) state=paused
  • Busy, try again (429) state=busy
  • Resetting (503) state=resetting
  • Failed run, trace kept state=failed

Trace panel

  • Complete, with spans state=done
  • Running state=streaming
  • Abstained state=abstain
  • Failed state=failed
  • Idle state=idle

Approval queue

  • Three proposals (conflict diff, stale, draft reply) state=pending
  • After approving state=resolved
  • Empty state=empty
