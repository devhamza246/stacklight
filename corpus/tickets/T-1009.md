# T-1009: Flow timed out after 5 minutes

Customer: Greywater Systems
Plan: Team
Priority: P3
Opened: 2026-09-15
Status: Resolved

## Customer report
A flow that calls a slow internal API fails with timeout.

## Resolution
Team plan run timeout is 5 minutes; Enterprise allows 15. Recommended splitting the flow into two chained flows or polling instead of waiting.
